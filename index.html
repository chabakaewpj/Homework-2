เหตุผลที่อยากเรียน Full Stack Web Development

  อยากเข้าใจกระบวนการพัฒนาเว็บทั้งระบบ(Frontend&Backend) เพื่อที่จะสามารถต่อยอดสร้างโปรเจกต์หรือเว็บแอปพลิเคชันของตนเองได้ และต้องการเพิ่มทักษะเพื่อเพิ่มโอกาสในการทำงานสาย Web Developer

ความคาดหวังต่อวิชานี้

  คาดหวังว่าจะได้ฝึกทำโปรเจกต์หลายๆ อย่าง และเข้าใจการทำงานของระบบหน้าบ้าน-หลังบ้าน มากขึ้น และสามารถนำความรู้ไปประยุกต์ใช้ในการทำงานจริงได้

สิ่งที่ต้องพัฒนาเกี่ยวกับทักษะ Programming และ แนวทางการพัฒนา

  จุดอ่อน: ยังคิดLogicที่ซับซ้อนหรือวางโครงสร้างระบบก่อนเริ่มเขียนโค้ดได้ไม่ค่อยคล่อง และยังไม่ค่อยเข้าใจเรื่องการจัดการฐานข้อมูลและการออกแบบAPI ฝั่งหลังบ้าน

  แนวทางการพัฒนา: ควรหมั่นฝึกฝนทำโจทย์Coding สม่ำเสมอ และฝึกเขียนFlowchart หรือวางแผนการทำงานก่อนลงมือเขียนโค้ด
